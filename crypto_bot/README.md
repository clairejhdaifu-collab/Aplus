# 덜 잃는 코인 자동매매 봇 (BTC · ETH)

목표는 **큰 수익이 아니라 큰 손실을 피하는 것**입니다.

## 어떻게 돌아가나

```
[매주 일요일]  GitHub Actions: 과거 데이터로 11개 지표 전략 × 파라미터 백테스트
               → 워크포워드 검증 → '덜 잃는 점수' 1위 전략 자동 선택 (= 학습)
[매일 00:15 UTC] GitHub Actions: 새 캔들 반영 → 오늘의 목표 비중(signal.json) → 모의매매
[매일 01:00 UTC] Claude 루틴: signal 을 읽어 Robinhood 에서 실제 매매 ($200 한도)
```

### 학습 = 워크포워드 재선택
- 과거 2년으로 고르고 → 다음 3개월에 적용, 이걸 3개월씩 밀며 반복합니다. 전략은 항상 처음 보는 구간으로 평가됩니다.
- 점수 = **연수익률 ÷ 얼서지수(Ulcer Index)**. 얼서지수는 하락이 얼마나 깊고 오래 갔는지를 재는 '고통 지수'입니다.
- 최대낙폭이 35%를 넘는 전략은 크게 감점합니다.
- 모든 전략이 마이너스면 **현금 보유**를 선택합니다.
- 기존 전략보다 10% 이상 나을 때만 교체합니다. 잦은 교체로 비용이 새는 걸 막기 위해서입니다.
- 선택 이력은 `reports/selection_history.csv`, 최신 리포트는 `reports/learn_report.md`에 남습니다.

### 쓰는 지표
이동평균 교차(SMA/EMA), 200일선 추세필터, MACD, RSI(모멘텀/눌림목), 볼린저밴드, 돈치안 돌파, 슈퍼트렌드, ADX, 시계열 모멘텀, 그리고 상위 3개 앙상블.

### 손실 방어 장치
| 장치 | 설명 |
|---|---|
| 롱 전용 | 공매도·레버리지 없음. 최악의 경우는 현금 |
| 변동성 타깃 | 시장이 거칠어지면 보유 비중을 자동으로 줄임 (연 35% 기준) |
| ATR 트레일링 스톱 | 고점에서 ATR×3 만큼 빠지면 즉시 현금화 |
| 킬스위치 | 봇 자산이 고점 대비 -25%면 전량 매도 후 정지 |
| 비용 반영 | 매매마다 0.6%(수수료+슬리피지)를 빼고 백테스트 |
| 매매 최소폭 | 비중 변화가 5% 미만이면 매매하지 않음 |

## 파일
- `config.json`: 모든 설정 (종목, 비용, 리스크 한도, Robinhood 예산)
- `bot/`: 지표, 전략, 백테스트, 학습, 주문 계획
- `state/`: 현재 선택된 전략, 오늘의 신호, 모의/실매매 장부
- `reports/`: 학습 리포트, 선택 이력
- `ROUTINE.md`: Robinhood 실매매 일일 절차

## 직접 돌려보기
```bash
pip install -r crypto_bot/requirements.txt
python crypto_bot/run.py learn    # 학습
python crypto_bot/run.py paper    # 오늘 신호 + 모의매매
python -m pytest crypto_bot/tests # 엔진 테스트
```
